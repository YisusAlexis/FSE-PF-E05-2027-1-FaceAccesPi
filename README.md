## Descripción del Proyecto

Este proyecto consiste en el desarrollo e implementación de un **sistema de control de acceso biométrico por reconocimiento facial**, diseñado para ejecutarse en una computadora monoplaca **Raspberry Pi 5**. 

El sistema captura video en tiempo real a través de un módulo de cámara, procesa los marcos utilizando algoritmos de visión por computadora para detectar y reconocer los rostros autorizados, y gestiona la apertura de accesos físicos o activación de indicadores mediante los pines GPIO. 

### Características Principales

* **Procesamiento Local:** Ejecución directa en la Raspberry Pi 5 sin dependencia obligatoria de la nube.
* **Control de Accesos:** Validación de identidad y activación de relevadores/actuadores para puertas o barreras.
* **Interfaz/Registro:** Registro de eventos (logs) con estampas de tiempo para cada intento de acceso.
* **Hardware Utilizado:** Raspberry Pi 5, Módulo de Cámara (Pi Camera / USB), Indicadores/Relevadores GPIO.
